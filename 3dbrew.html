🚀 Scroll-World 整合代碼指南

1. 引入 Scrubber 引擎（無任何第三方依賴）：

import { ScrollWorldScrubber } from './src/scrubber.js';

const engine = new ScrollWorldScrubber({
  canvas: document.getElementById('worldCanvas'),
  lerpFactor: 0.08, // 慣性平滑度
  trackHeight: 4500, // 虛擬高度
  onProgress: (p, velocity) => {
    console.log(`Global Progress: ${(p * 100).toFixed(1)}%`);
  }
});

2. 替換成你自己的 AI 影片 (GOP=1)：

# 終端轉碼指令 (確保 60FPS 搓動零遲滯)
ffmpeg -i my_dive.mp4 -c:v libx264 -g 1 -keyint_min 1 -crf 22 -an output_gop1.mp4
